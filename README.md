# Mis Finanzas

App web de presupuesto por sobres para ingresos variables. Se instala en el iPhone desde Safari
(Compartir → Agregar a pantalla de inicio) y funciona sin conexión.

Este repositorio solo contiene el código de la app. Los datos de cada persona viven en su dispositivo
y, si activa la sincronización, en su propio repositorio privado, cifrados con AES-GCM y una contraseña
que solo ella conoce.
